# MoodClock

침실 모니터를 밤새 켜 두는 용도로 만든 macOS 시계·날씨 화면입니다.
iOS 스탠바이를 참고하되 배경을 **완전한 검정(#000000)** 으로 유지해 OLED에서는 배경 픽셀이 실제로 꺼지고,
눈부심 없이 대비만 남도록 색과 밝기를 설계했습니다.

## 설치

1. `.dmg` 파일을 다운로드한 뒤 더블클릭합니다.
2. **MoodClock** 아이콘을 **Applications(응용 프로그램)** 폴더로 드래그합니다.
3. Launchpad 또는 Applications에서 앱을 실행합니다.

### 처음 실행할 때

Apple 공증(Notarization)을 마친 앱이라 보안 경고로 차단되지 않습니다.
인터넷에서 받은 앱에 공통으로 나타나는 확인 창에서 **열기**를 한 번 누르면 되고, 이후에는 표시되지 않습니다.

## 기능

- **시계 하나만 크게** 또는 **좌우 두 개**, **가운데 + 네 모서리** 중에서 화면 구성을 선택
- 각 자리에 **아날로그 시계 · 디지털 시계 · 날씨 · 날짜**를 자유롭게 배치
- **아날로그 시계 5종** — 침을 선이 아니라 실제 시계 침 단면대로 그려 초침 끝까지 또렷합니다
- **디지털 시계 5종** — 넘어가는 플립 카드, 도트 매트릭스 등 스타일마다 초를 다르게 표현
- **인터넷 시각 보정** — 시각 서버 네 곳에 동시에 물어 왕복 지연이 가장 짧은 응답을 사용하고, 숫자가 바뀌는 순간도 참 시각의 정각 경계에 맞춥니다
- **날씨** — Open-Meteo(키 불필요) 또는 기상청 단기예보(공공데이터포털 무료 키) 중에서 선택
- **지역 표시** — "서울"이 아니라 **"서울 강남구", "성남 정자동"** 처럼 동네 단위로 표시
- **야간 팔레트 6종** — 앰버(청색광 최소) · 엠버(심야) · 문라이트 · 세이지 · 블라썸 · 잉크
- **자동 밝기** — 지정한 시각부터 서서히 어두워지고 아침에 되돌아옵니다
- **번인 방지** — 표시 내용이 몇 분 주기로 아주 조금씩 떠돌아 같은 픽셀이 밤새 켜져 있지 않게 합니다
- **디스플레이 절전 차단** — 시스템 설정을 건드리지 않고 앱이 켜져 있는 동안만 화면을 유지
- **4K·UWQHD 대응** — Retina가 아닌 화면에서는 두 배 해상도로 그린 뒤 축소해 계단 현상을 없앱니다
- 마우스를 움직였을 때만 조작 막대가 잠깐 나타나고, 그 외에는 포인터까지 감춰집니다

## 사용 방법

### 1. 화면 구성 정하기

`⌘,` 로 설정을 열고 **레이아웃** 탭에서 단일 · 좌우 · 모서리 중 하나를 고릅니다.
미리보기에서 원하는 자리를 **직접 클릭**하면 그 자리에 넣을 내용과 디자인을 바로 고를 수 있습니다.

### 2. 침실 모니터로 옮기기

창을 침실 모니터로 옮긴 뒤 `⌃⌘F` 로 전체화면으로 전환합니다.
설정 › 화면에서 **실행하면 전체화면으로 시작**을 켜 두면 다음부터는 바로 전체화면으로 열립니다.

### 3. 밝기 맞추기

설정 › 화면에서 낮 밝기와 밤 밝기, 어두워지기 시작할 시각을 정합니다.
검정 배경 위에서 밝기를 낮추는 것은 곧 화면이 내는 빛을 줄이는 것이라, OLED에서는 전력도 함께 줄어듭니다.

### 4. 날씨 지역 설정

설정 › 날씨에서 **동네 이름**으로 검색합니다 (예: `강남구`, `정자동`, `성남시 분당구`).
'현재 위치 사용'을 켜면 위치 권한을 요청한 뒤 자동으로 지역을 찾습니다.

| `⌘T` | 시각 다시 동기화 |

## 설정

| **레이아웃** | 화면 구성과 자리별 위젯·디자인 선택 |
| **모양 → 색** | 야간 팔레트 6종 |
| **모양 → 서체** | 라운드 · 디스플레이 · 모노 · 세리프와 굵기 (아날로그 침 두께에도 함께 적용) |
| **모양 → 시간 표시** | 24시간제, 초 표시, 초침을 부드럽게 흐르게 |
| **날씨 → 제공자** | Open-Meteo 또는 기상청 단기예보 |
| **날씨 → 위치** | 동네 이름 검색 또는 현재 위치 사용 |
| **날씨 → 애니메이션** | 비·눈이 떨어지는 움직임 (기본 꺼짐, 전력을 아끼기 위함) |
| **화면 → 밝기** | 자동 밝기 시간대와 낮·밤 밝기 |
| **화면 → 번인 방지** | 표시 내용이 떠도는 범위 |
| **화면 → 렌더링** | 자동 · 항상 고품질 · 성능 우선 |
| **시간** | 인터넷 시각 보정 사용 여부와 현재 보정값 확인 |

## 날씨 출처

**Open-Meteo**는 API 키 없이 바로 동작하며 기본값입니다.

**기상청 단기예보**를 쓰려면 [공공데이터포털](https://www.data.go.kr/data/15084084/openapi.do)에서
‘기상청_단기예보 조회서비스’를 신청하고, 받은 **일반 인증키(Decoding)** 를 설정 › 날씨에 붙여넣으면 됩니다.
국내 포털 날씨가 근거로 삼는 원본 관측·예보값을 그대로 사용합니다.
